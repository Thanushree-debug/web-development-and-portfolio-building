# IPL 2026 Ticket Booking Website

## Project Description

This project is a responsive **IPL 2026 Ticket Booking Website** created using HTML and CSS. The website provides information about IPL teams, match schedules, ticket prices, ticket booking, booking summaries, and stadium guidelines.

The project was developed as part of the HTML and CSS activities and was tested in a web browser using VS Code.

## Technologies Used

* HTML
* CSS3
* Flexbox
* CSS Grid
* Media Queries
* VS Code

## Features

### 1. Navigation Bar

* IPL 2026 Ticket Booking logo/title
* Matches section
* Book Ticket section
* My Bookings section
* Guidelines section
* Navigation links to different sections of the webpage

### 2. Hero Section

* Main tagline: **"Experience The Stadium Energy Live!"**
* View Schedule button
* Book Ticket button
* Gradient background

### 3. About IPL 2026

* Introduction to IPL
* List of popular IPL teams
* List of major match venues

### 4. Match Schedule

* Match number
* Teams
* Date and time
* Venue
* General, Premium and VIP ticket prices
* Book button for each match
* Team selection filter

### 5. Ticket Booking Form

The booking form contains:

* Match selection
* Stand category
* Number of tickets
* Name
* Email
* Phone number
* Confirm Booking button

### 6. Booking Summary

The booking summary displays:

* Selected match
* Stand category
* Ticket price
* Number of tickets
* Total amount

### 7. My Ticket Bookings

An empty table is provided for storing future booking records.

### 8. Stadium Guidelines

Three guideline cards are provided:

* Ticket Verification
* ID Proof Requirement
* Prohibited Items

### 9. Responsive Design

The website is responsive and adapts to different screen sizes using:

* Flexbox for the navigation layout
* CSS Grid for the booking form and summary
* Horizontal scrolling for tables on small screens
* Media queries for tablet and mobile devices

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html`.
4. Run the webpage using Live Server or open the HTML file directly in a browser.
5. Resize the browser window to check the responsive layout.

## Activities Completed

### Activity 1 – HTML Structure

Created the complete website structure using semantic HTML elements.

### Activity 2 – CSS Styling

Applied colors, typography, buttons, tables, forms, cards, shadows, borders and other visual styling using CSS.

### Activity 3 – Responsive Layout

Implemented Flexbox, CSS Grid, horizontal table scrolling and media queries for tablet and mobile layouts.

## Note

This project focuses on the **front-end structure, styling and responsive design** of the IPL ticket booking website. Dynamic booking, automatic price calculation and functional team filtering would require JavaScript and are not included in these activities.
